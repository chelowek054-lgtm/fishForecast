# Подмена документа модели меняет расчёт

Два утверждения в одном прогоне:

1. Расчёт со встроенным документом даёт те же оценки, что и версия на
   константах, — набор тест-векторов «вход → ожидаемая оценка».
2. Документ с изменённым весом давления меняет оценку предсказуемо: вес выше —
   отклонение давления влияет сильнее.

Первое ловит регрессию при переносе, второе доказывает, что документ вообще
читается.
