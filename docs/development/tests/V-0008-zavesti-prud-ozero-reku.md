# Пруд, озеро и участок реки заводятся по шагам

В скачанном районе, с выключенной сетью:

1. Пруд: граница совпадает с водой на карте, тип, глубины и виды видны в
   карточке.
2. Озеро с островом: остров не входит в водоём.
3. Участок реки: граница — русло в кадре, название — с линии реки.
4. У заведённого водоёма дописан ещё один вид — он виден в карточке.
