# Улов с одного телефона виден на стене другого

Сервер поднят в docker compose, два устройства — два клиента теста:

1. Первый публикует улов с фото — второй видит запись в общей ленте и в ленте
   района.
2. Второй ставит отметку и пишет комментарий — первый их видит.
3. Неопубликованный улов первого не появляется ни в одной ленте.
4. В записи место — район, а не координаты точки.
