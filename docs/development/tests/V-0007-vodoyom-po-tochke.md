# Водоём находится по точке нажатия

1. Точка внутри границы из нескольких кусков находит свой водоём.
2. Точка в острове внутри озера водоём не находит.
3. Из двух водоёмов, чьи рамки пересекаются, находится тот, в чью границу
   точка попала.
4. Точка на воде вне известных водоёмов — пустой ответ, а не ближайший.
