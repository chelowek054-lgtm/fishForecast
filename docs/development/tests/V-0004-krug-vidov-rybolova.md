# Круг видов рыболова собирается из его данных

1. Виды точек, уловов и выездов вместе дают круг; повтор считается один раз.
2. Вид, удалённый из справочника, в круг не попадает, даже если остался у
   старого улова.
3. Пустой круг — окно ищется среди всех видов.

Картинка приложения и цвет значка проверяются глазами при закрытии T-0004.
