# Число структур не множит балл места

1. Пять структур «за рыбу» дают тот же бонус, что самая сильная из них.
2. Структура «за» и структура «против» дают единицу плюс обе: коряжник на
   гнилом иле хищнику — 0.95.
3. Два родника холодят место так же, как один; приток вместе с наветренным
   берегом добавляют кислорода столько же, сколько один приток.
4. Одна структура — прежние числа: коряжник хищнику 1.25, гнилой ил 0.7.
