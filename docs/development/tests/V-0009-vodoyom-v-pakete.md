# Водоём переживает пакет района

1. Водоём с границей, типом, глубинами и видами проходит кодирование и разбор
   без потерь.
2. Пакет без водоёмов читается как прежде.
3. Пакет с водоёмами читается сборкой, которая о них не знает: незнакомый
   раздел пропускается, остальное приезжает.

Серверная часть проверяется в T-0013 своим прогоном.
