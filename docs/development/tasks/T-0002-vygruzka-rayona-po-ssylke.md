## Что делаем

(`SavedMapEntity.contains`), хотя принадлежность с миграции 26 — ссылка.

Заодно экран хранилища перестал обещать в пакете «зоны с секторами»: их нет с
29.08.2026.

Документ не правится: принадлежность по ссылке уже описана, код её не
выполнял.
