# Снять из сводной карты узлы-каталоги

## Что делаем

В M-0009 попали девять модулей, которые на деле каталоги: `data/local`,
`data/local/dao`, `data/local/entities`, `data/location`, `data/remote`,
`data/repository`, `data/sensor`, `ui/navigation`, `ui/session`, — и 28
связей к ним. Это наследство прежних карт, описывавших пакет целиком. Скрипт
сборки снимал такие узлы по имени, а эти записаны полным путём и прошли мимо.
Каждый файл внутри уже описан сам, так что узлы-каталоги только двоят граф.

M-0012 — та же сводная карта без них, заменяет M-0009. Убрать узлы блоком
`removed` нельзя: консоль потребовала бы, чтобы убранные связи исчезли из
кода, а строки `import`, на которые они опираются, на месте — их держат
связи файлов.

Ошибка сборки карты, а не кода: код не меняется.

## Готово, когда

M-0012 подтверждена, M-0009 помечена заменённой, V-0011 прошла.
