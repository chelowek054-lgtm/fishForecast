# Вынести веса модели клёва в документ знаний

## Что делаем

Заводим схему `fishforecast.bite-model/1` и кодек рядом с существующими
кодеками знаний. Расчёт читает веса, допуски и пороги из документа вместо
констант. Первая версия документа повторяет нынешние значения: 0.35 давление,
0.20 тенденция, 0.30 свет, 0.15 ветер, допуск давления 12 мм рт. ст.

Записываем версию документа рядом с уловом — без этого сверка прогноза с фактом
через полгода бессмысленна.

## Чего не делаем

Не меняем механику: ограничители по-прежнему перемножаются, условия
складываются с весами. Документ задаёт числа, код задаёт способ.

Не трогаем внешнюю таблицу весов (0.40 / 0.30 / 0.15 / 0.10 / 0.05) — она
кандидат, и решает её судьбу прогон по журналу, а не эта задача.

## Готово, когда

- Подмена документа меняет расчёт.
- Встроенный документ даёт в точности прежние числа.
- Тест-векторы проходят.
- В справочнике видно, какая версия модели действует.
