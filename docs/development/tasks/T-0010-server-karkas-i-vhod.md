# Сервер — где живёт, каркас и вход устройства

## Что делаем

Первым — ADR «Где живёт сервер». Предложение: каталог `server/` в этом же
репозитории — контракт `openapi.yaml` уже здесь, и правило «сначала
контракт, потом код» проще держать одним изменением, чем двумя репозиториями.
Решение за человеком.

Потом каркас по [server/overview.md](../../../app/docs/architecture/server/overview.md)
и общим практикам консоли (A-0002 FastAPI и чистая архитектура, A-0003 docker
compose): FastAPI, PostgreSQL + PostGIS, миграции, `X-Correlation-Id`, первый
маршрут — `POST /v1/auth/device`.

## Чего не делаем

Ни стены, ни знаний, ни синхронизации — только то, без чего их не на что
положить.

## Готово, когда

Сервер поднимается одной командой, устройство получает токен, тест маршрута
зелёный.
