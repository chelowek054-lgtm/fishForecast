# Водоёмы на общем сервере

## Что делаем

Контракт первым: ресурса водоёмов в
[openapi.yaml](../../../app/docs/architecture/server/api/openapi.yaml) нет —
поиск по охвату, публикация, дописывание видов, слияние по `uid`. Потом сервер
и клиент: заведённый водоём публикуется отдельным действием, чужие приезжают
при сети и остаются на устройстве.

## Чего не делаем

Права на правку чужого водоёма — пока «дописать вид может любой, менять
границу и глубины — автор»; вес автора — позже.

## Готово, когда

Водоём, заведённый на одном телефоне, приезжает на другой с сервера; V-0009
прошла для пакета.
