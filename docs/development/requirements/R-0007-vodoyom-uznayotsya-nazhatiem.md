# Водоём на карте узнаётся нажатием

Нажатие на воду открывает карточку водоёма из базы приложения: название, тип,
глубина ямы и средняя глубина, виды, которые там водятся, описание. Водоёма в
базе нет — карточка говорит об этом и предлагает завести его.

Работает без сети: граница водоёма хранится на устройстве, и нажатие
сверяется с ней, а не с сервером.

Выполнено, когда нажатие внутри границы водоёма из базы открывает его
карточку, а нажатие на воду вне известных водоёмов предлагает завести новый.
