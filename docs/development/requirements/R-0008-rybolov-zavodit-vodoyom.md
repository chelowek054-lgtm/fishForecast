# Рыболов заводит водоём сам

Любой рыболов добавляет водоём по шагам:

1. приближает карту так, чтобы в кадре был нужный водоём, и нажимает
   «Добавить водоём» — граница берётся из воды векторного слоя в кадре;
2. подтверждает границу;
3. выбирает тип из словаря;
4. вводит глубину ямы и среднюю глубину;
5. отмечает виды из справочника;
6. пишет описание.

Река заводится участком: кадр задаёт, какой её отрезок имеется в виду. Виды у
готового водоёма дописывает любой рыболов.

Выполнено, когда пруд, озеро и участок реки заводятся без ручного обвода
границы — и без сети, если район скачан.
