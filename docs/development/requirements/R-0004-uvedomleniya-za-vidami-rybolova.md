# Уведомление зовёт только за теми видами, за которыми рыболов ездит

Сегодня окно клёва ищется среди всех видов справочника: налим, которого
рыболов никогда не ловил, может позвать его в ночь на субботу. Уведомление —
единственное, что приложение делает без спроса, и шум здесь дороже пропуска.

Круг видов виден по данным самого рыболова — виды его точек, уловов и
выездов, — отдельной настройки для этого не нужно. Уведомление узнаётся с
первого взгляда: в нём картинка приложения, а не только белый силуэт.

Выполнено, когда:

- уведомление называет вид только из круга рыболова, если круг не пуст;
- в раскрытом уведомлении видна картинка приложения, значок в шторке — в цвете
  иконки.

Устройство — [alerts.md](../../../app/docs/architecture/client/alerts.md),
«За кем звать» и «Значки».
