# Заведённый водоём доступен другим рыболовам

Водоём — знание о месте, а не секрет: его граница, тип, глубины и виды полезны
каждому, кто приедет туда же. Он уходит к другим — сначала в пакете района,
как уже уходят точки, затем через общий сервер для всех.

Точки рыболова в водоём не входят и по-прежнему уходят только отдельным
выбором.

Выполнено, когда водоём, заведённый на одном телефоне, появляется на другом —
из пакета района без сети и с сервера при сети — со своими видами, а личные
точки при этом не уходят.
