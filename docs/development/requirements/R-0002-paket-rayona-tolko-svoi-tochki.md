# Точка уходит в пакет района только со своим районом

С миграции 26 точка принадлежит району ссылкой `fishing_spots.mapId`, а не
рамкой ([04-data-dictionary.md](../../../app/docs/architecture/04-data-dictionary.md),
«Точка принадлежит району»). Пакет района обязан следовать той же
принадлежности: точка на стыке двух районов уходит только со своим, чужая
точка внутри рамки не уходит вовсе.

Выполнено, когда в пакете района ровно его точки — не больше и не меньше.
