# Экран сборов отвечает на четыре вопроса

Что меняется в устройстве для T-0005: ничего. Карта заведена потому, что
задача — новое поведение, и это надо сказать явно, а не молчанием.

Три блока, которые перестают выдавать всем одно и то же, берут данные,
которые план уже читает:

- «Куда идти» — любимые структуры вида: `FishingStrategy` и так разбирает их
  через `decodeBaits` из `domain/fish/FishCatalog.kt`;
- «Как пройдут сутки» — световой профиль вида: `decodeLightActivity` лежит в
  том же `FishCatalog.kt`, `lightActivity` — в `domain/light/LightPhase.kt`, с
  которым план уже связан;
- «Монтаж» — `gear_note` структур и гильдия способа из словаря знаний, который
  план получает целиком.

Шапка и группы собираются в `SessionPanel.kt` из тех же полей
`FishingStrategy`. Новых модулей, связей, источников данных и экранов нет.
