# Решения (ADR)

Каждое решение — отдельный файл: контекст, выбор, последствия и то, что было
отвергнуто вместе с причиной. Принятое решение не переписывается: если оно
перестало быть верным, пишется новое со ссылкой на заменяемое, а у старого
меняется статус.

Отвергнутые варианты записываются намеренно. Без них через полгода начинается
разговор «а почему бы нам не», и всё обсуждается заново.
