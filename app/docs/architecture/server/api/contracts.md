# Правила контрактов

Контракт — это то, что согласуется до кода. Клиент, сервер и админка могут
писаться параллельно ровно потому, что форма разговора зафиксирована здесь и в
двух соседних файлах: [openapi.yaml](openapi.yaml) для запросов-ответов и
[asyncapi.yaml](asyncapi.yaml) для чатов и уведомлений.

## Порядок работы

1. Изменение начинается с правки спецификации.
2. Спецификация проходит проверку схемы (парсится, все ссылки разрешаются).
3. Только после этого пишется код — на сервере из неё же генерируются модели
   Pydantic, на клиенте описываются DTO.
4. Код, разошедшийся со спецификацией, считается сломанным. Не «опережающим
   документацию», а сломанным.

## Версии

- Путь несёт поколение: `/v1/...`. Поколение меняется, только когда ломается
  совместимость.
- Внутри поколения разрешено **добавлять**: новые поля, новые эндпойнты, новые
  значения перечислений с понятным поведением по умолчанию.
- Запрещено: удалять поле, менять его тип, менять смысл значения, делать
  необязательное обязательным.
- Клиент обязан игнорировать незнакомые поля. Это правило уже действует в кодеках
  (`ignoreUnknownKeys = true`) и распространяется на весь API.
- Документы знаний и пакеты районов версионируются **отдельно** от API — у них
  своя схема вида `fishforecast.knowledge/1`. API может быть `/v1`, а документ
  внутри — третьего поколения; это разные вещи и разные причины ломаться.

## Обязательные заголовки

| Заголовок | Направление | Зачем |
|---|---|---|
| `X-Correlation-Id` | Запрос и ответ | Сквозной идентификатор потока. Рождает клиент, сервер протаскивает во все внутренние вызовы и пишет в каждую строку лога. Нет заголовка — сервер создаёт свой и возвращает |
| `Authorization: Bearer` | Запрос | Кроме публичного чтения знаний |
| `Idempotency-Key` | Любой небезопасный запрос | Клиент может отправить одно и то же дважды: связь на воде рвётся посреди запроса |
| `If-None-Match` / `ETag` | Документы знаний, ленты | Не качать то, что не менялось |
| `If-Match` | Обновление района | Оптимистическая блокировка по версии |

## Идемпотентность

Очередь исходящего на клиенте гарантирует «хотя бы один раз», а не «ровно один
раз». Значит, сервер обязан быть готов к повтору:

- ключ идемпотентности хранится сутки вместе с результатом;
- повтор с тем же ключом возвращает **тот же** ответ и не создаёт вторую запись;
- повтор с тем же ключом, но другим телом — ошибка `409`, а не тихая перезапись.

## Ошибки

Единый формат — Problem Details (RFC 7807):

```json
{
  "type": "https://fishforecast/errors/region-version-conflict",
  "title": "Район изменён другим устройством",
  "status": 409,
  "detail": "Ваша версия 4, актуальная 6",
  "correlation_id": "01J9...",
  "instance": "/v1/regions/9f2c.../"
}
```

| Код | Когда | Что делает клиент |
|---|---|---|
| `400` | Тело не проходит схему | Не повторяет, показывает причину |
| `401` | Нет или истёк токен | Обновляет токен и повторяет один раз |
| `403` | Чужая запись | Не повторяет |
| `404` | Нет записи | Снимает из очереди |
| `409` | Конфликт версий или ключа идемпотентности | Тянет актуальную версию и решает по правилам слияния |
| `413` | Слишком большой файл | Не повторяет, объясняет |
| `422` | Схема документа знаний или пакета не та | Не повторяет, показывает причину прямо из текста |
| `429` | Лимит | Ждёт по `Retry-After` |
| `5xx` | Сбой сервера | Повторяет с возрастающей паузой |

Сообщения — на русском и понятные человеку: их видит рыболов, а не только лог.

## Пагинация

Курсорная, не постраничная: лента меняется, пока её листают.

```
GET /v1/wall?limit=20&cursor=eyJ0IjoiMjAyNi0wOC0yOVQxMDowMCJ9
→ { "items": [...], "next_cursor": "..." }
```

`next_cursor` отсутствует — данные кончились.

## Большие файлы

Фото и промеры эхолота не ходят через шлюз телом запроса. Клиент просит
подписанную ссылку, кладёт файл в объектное хранилище напрямую и присылает ключ.
Так шлюз не держит соединение на десятки мегабайт и не становится узким местом.

## Что не является контрактом

Пакет района (`.ffpack`) и документы знаний — самостоятельные форматы, описанные
в [RegionPack.md](../../../RegionPack.md) и
[client/knowledge-updates.md](../../client/knowledge-updates.md). API их
переносит, но не определяет: тот же пакет ходит файлом через мессенджер, где
никакого API нет.
