# Матрица прослеживаемости

Связывает три вещи: чего мы хотим, где это описано и чем проверяется. Смысл
таблицы — увидеть строку без проверки. Такая строка означает, что требование
живёт на честном слове.

Матрица ведётся: новая фаза добавляет строки, закрытая — проставляет проверки.

## Требования

| № | Требование | Откуда взялось |
|---|---|---|
| R-01 | Решение «ехать или нет» принимается без сети | Инвариант, [00-manifest.md](00-manifest.md) |
| R-02 | Знание обновляется без релиза приложения | Задача админки |
| R-03 | Негодный документ знаний не ломает расчёт | Опыт: остаться без словарей значит остаться без приложения |
| R-04 | Расчёт объясним: у каждого фактора есть причина | Экран показывает причину, а не число |
| R-05 | Расчёт воспроизводим спустя время | Сверка прогноза с фактом |
| R-06 | Личное не покидает устройство само | Приватность точек и уловов |
| R-07 | Изменение, сделанное без сети, не теряется | Очередь исходящего |
| R-08 | Повторная отправка не создаёт дублей | Обрыв связи на воде |
| R-09 | Конфликт версий района разрешается без потери данных | Совместная правка |
| R-10 | Старая сборка приложения продолжает работать после обновления сервера | Обновления на телефонах идут месяцами |
| R-11 | Поток данных восстановим по логам | Разбор жалоб |
| R-12 | Глубины района берутся из промера, ручной ввод остаётся главнее | [ADR-0007](adr/0007-bathymetry-sources.md) |
| R-13 | Новая версия коэффициентов выпускается только с доказательством улучшения | [ADR-0003](adr/0003-bite-model-out-of-code.md) |
| R-14 | Сообщение чата не теряется при обрыве соединения | [ADR-0009](adr/0009-realtime-transport.md) |

## Как пользоваться

- Новое требование — сначала строка здесь, потом код.
- Закрытая фаза не считается закрытой, пока её строки не получили проверку.
- Проверка «обзор экранов» допустима там, где автоматический тест дороже пользы,
  но она должна быть названа явно, а не подразумеваться.
